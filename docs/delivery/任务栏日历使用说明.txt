Focalboard 任务栏假勤日历 1.0.0
================================

点击任务栏托盘图标，弹出 Focalboard 的假勤助手月历，直连远程服务器。


一、运行条件
------------
1. Windows 10 / 11（64 位）
2. Microsoft Edge WebView2 Runtime（Win10/11 一般已内置；没有则从微软官网安装）


二、首次使用
------------
1. 双击 FocalboardCalendar.exe，任务栏托盘出现日历图标
2. 右键托盘图标 -> 设置服务器地址，填写 Focalboard 地址，例如：
       https://your-server:5443
       http://192.168.1.100:8088
3. 点击托盘图标弹出窗口，在网页里正常登录（本程序不保存账号密码）
4. 登录后点击托盘图标即可直接看到假勤月历；窗口失去焦点会自动收起


三、离线与同步
--------------
- 联网时自动缓存假勤汇总、月历、农历/节气与当前用户信息，位置：
      %LOCALAPPDATA%\FocalboardCalendar\cache\<服务器地址>\
- 断网时点击托盘图标，显示上次同步的本地月历，底部提示“离线模式”
- 每 15 秒探测一次服务器，恢复联网后自动回到在线页面并同步

配置文件：%APPDATA%\FocalboardCalendar\config.ini
日志文件：%LOCALAPPDATA%\FocalboardCalendar\app.log


四、常见问题
------------
- 弹出空白窗口：确认已安装 WebView2 Runtime，且服务器地址可访问
- 一直显示离线：检查地址、端口、防火墙；服务器恢复后最多等待 15 秒
- 显示的余额不是最新：联网状态下打开一次弹窗即会同步
- 托盘图标不见了：程序退出，重新运行；或查看日志文件


五、说明
--------
- 本程序只读取数据，不修改服务器内容
- 内网自签名 HTTPS 证书会被接受，请仅在自己信任的服务器上使用
- 源码与构建方法见 README.md（.NET Framework 4.8，运行 build.bat）
