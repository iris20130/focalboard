Focalboard 局域网版（Windows，v8.0.0 · 假勤版）
英文说明见同目录 UserGuide_EN.txt。
================================

一、启动
  1. 双击 Focalboard.exe。
  2. 托盘出现图标，浏览器会自动打开（优先使用局域网地址，如 http://192.168.1.100:8088/）。
  3. 首次使用：打开页面后点“注册”创建第一个账号，
     这个账号会自动成为管理员（只有第一个注册的账号是管理员）。
  4. 其他同事请让管理员生成邀请链接后再注册（密码至少 8 位）：
     管理员登录后点左下角用户名 → “邀请使用者” → 复制注册链接。
     系统不预置任何账号，也没有默认密码，不会强制修改密码。
  5. 登录修复：输入账号密码点“登录”后会直接进入看板，不需要再手动刷新页面。
     如果从旧版升级，请先按 Ctrl+F5 强制刷新一次浏览器，避免加载到旧的前端缓存。

二、开机自启动与静默启动
  1. 默认已开启“开机自动启动”：登录 Windows 后程序在后台静默启动，
     不弹出浏览器、不弹任何窗口，只在托盘显示图标，服务随即可用。
  2. 第一次运行 Focalboard.exe 时会自动写入启动项
     （HKCU\Software\Microsoft\Windows\CurrentVersion\Run，键名 FocalboardLAN），
     只对当前用户生效，不需要管理员权限。
  3. 开启 / 关闭：右键托盘图标 → “开机自动启动（登录后静默运行）”，
     打勾表示已开启。关闭后启动项会被删除，下次登录 Windows 不再自动运行。
  4. 手动静默启动：Focalboard.exe --silent
     静默启动时不打开浏览器；需要访问时右键托盘 → “打开 Focalboard”。
  5. 移动或改名程序目录后，请在新位置双击运行一次 Focalboard.exe，
     启动项会自动更新为新路径（否则开机时仍指向旧路径）。
  6. 开机后找不到托盘图标：先检查托盘折叠区，再确认启动项未被安全软件拦截。
  7. 静默启动或开机自启时如果服务启动失败，不会弹窗打扰，
     原因记录在 data\focalboard.log，可右键托盘 → “查看日志”。

三、让同事访问
  1. 确保这台电脑和同事在同一局域网（同一 Wi-Fi 或同一交换机）。
  2. 右键托盘图标 → “局域网地址（点击复制）”，把地址发给同事。
  3. 如果同事打不开：右键托盘 → “允许局域网访问（防火墙）”，在系统弹窗中选“是”。
  4. 邀请同事注册：
     登录后点左下角用户名 → “邀请使用者” → 复制注册链接发给同事。
     提示：请用局域网地址登录后再复制链接，这样链接里的地址才是局域网地址。

三点五、统一访问地址（建议）
  1. 本机 IP 如果会变化，同事收藏的地址容易失效。建议二选一：
       - 在路由器里给这台电脑绑定静态 IP / DHCP 保留地址；
       - 或在 config.json 里把 serverRoot 改成固定的规范地址
         （如 http://192.168.1.100:8088 或内网域名），保存后重启程序。
  2. 邀请链接、推送消息里的跳转链接都取自 serverRoot / 推送设置里的“链接地址”，
     统一改一处即可，全员收到的地址保持一致。

四、固定端口与配置文件
  端口固定为 8088，配置文件是 config.json。
  如果修改端口，托盘菜单会自动读取新端口；同时请放行新端口的防火墙。
  访问格式：http://本机IP:8088/
  config.json 里每个配置项前面都有中文注释（// 开头），可以直接改，
  保存后重启程序生效。注释不影响程序读取配置。

五、任务模板（中英双语）
  1. 新建看板时可以选择内置模板：会议议程、项目任务、销售管道、个人任务、
     冲刺规划、路线图、团队回顾、OKR 等，共 13 套。
  2. 模板会跟随界面语言自动切换：
       界面语言为中文 → 显示中文模板（名称、简介、属性、选项、视图、卡片标题）
       界面语言为英文 → 显示英文模板
     切换方法：左下角用户名 → 设置 → 语言。
  3. 自己创建并保存的模板不受语言限制，中英文界面都会显示。

六、到期状态（自动计算）
  1. 到期状态是一个只读的“公式”属性，根据看板里的日期属性自动判断：
       已逾期 / 今天到期 / 即将到期 / 正常 / 未设置日期
  2. 添加方法：看板右上角“添加属性” → 到期状态。
  3. 判断依据：优先使用名称含“截止 / 到期 / due / deadline”的日期属性；
     没有这样的属性时，使用看板里的第一个日期属性。
  4. 卡片上会显示彩色标签：红色已逾期、橙色今天到期、黄色即将到期、绿色正常。
  5. “即将到期”的天数范围跟随本机“到期提醒”里的提前天数设置（默认 7 天）。

七、筛选即将到期的卡片
  1. 看板右上角“筛选” → 添加筛选条件。
  2. 选择“到期状态”属性，可以筛选：
       已逾期 / 今天到期 / 即将到期 / 正常 / 未设置日期
  3. 选择任意日期属性，还可以使用新的日期条件：
       “将在多少天内到期”（填写天数，例如 7）
       “已逾期”
  4. 筛选条件可以和其它属性条件组合使用，视图会实时更新。

八、右侧提醒栏与顶部提示栏
  1. 布局：最左边的看板导航栏保持上下贯通；看板右侧是“提醒栏”，
     顶部提示栏只横跨看板和提醒栏，不覆盖左侧导航栏。
  2. 打开/关闭提醒栏：点顶部提示栏最右边的“提醒”按钮。
     有逾期/临期或待返卡片时提醒栏会自动展开；都没有时自动收起，
     仍可手动打开查看设置。
  3. 调整宽度：拖动看板与提醒栏之间的竖线，宽度会自动记住。
  4. 提醒栏按看板分组，每个看板显示三个数字：
       逾期（红）、临期（橙）、待返（紫）。
     顶部三个复选框分别控制列表显示：
       - 逾期 / 临期：显示有日期的逾期、临期卡片；
       - 待返：显示所选“逾期/临期日期”属性为空的卡片。
     打开“待返”时，逾期/临期自动关闭；关闭“待返”时，逾期/临期自动恢复。
  5. 点具体卡片会跳到对应看板并定位到那张卡片，卡片周围会闪烁光环；
     鼠标移到卡片上后光环自动停止。
     如果卡片被当前视图的筛选/隐藏挡住，会自动打开该卡片的详情窗口。
  6. 点提醒栏顶部的齿轮打开设置（每个账户独立保存），包含：
       推送开关、推送渠道、提前天数、检查间隔、推送日与推送时段、
       Webhook 与签名密钥、立即推送按钮、跳转链接地址、
       按属性统计（每个板块单独选择属性，看板行下方会显示分项数量）、
       逾期/临期日期（每个板块单独选择用哪个日期属性计算逾期、临期和待返）、
       实际完成日期（每个板块单独设置，见“八点五”）、
       工时·跨度（每个板块单独选择开始/结束日期属性，见“八点六”）、
       逾期/临期/待返的文字颜色和卡片左边框颜色（改完立即生效）。
  7. 提前天数同时决定“即将到期”的判断范围。
  8. 提醒定时自动刷新；共享链接（只读访客）页面不显示提醒。
  9. 顶部提示栏：
       - 本版本默认已开启（config.json 里 topBarEnabled = true，可改回 false 关闭）。
       - 有逾期/临期时显示“最近有点忙”，没有时显示“近期无事项”，
         后面随机接一句语录，每次刷新网页换一句。
       - 单行显示；文字太长时会从提示语后面滚动，鼠标移上去暂停。
       - 点击提示文字可隐藏，状态会自动记住；点击同一位置的空白处可重新显示。
       - 语录在同目录 quotes.txt 里维护，分 [idle]（闲）和 [busy]（忙）两节，
         一行一句，改完刷新网页即可生效，不需要重启服务。
       - 日期条整行居中显示，与两侧文字自适应排布；日期后面依次是
         公历/星期、干支纪年与农历（如“丙午年·十月十五”）、调休年假徽标。

八点五、实际完成日期（自动填写）
  1. 每个看板会自动增加一个日期属性“实际完成日期”。
  2. 卡片状态改为“已完成”时，自动写入当天日期；改为其他状态
     （进行中、取消、沉默等）时自动清空。
  3. 右侧提醒栏 → 齿轮 → “实际完成日期 · 看板名” 可逐个看板启用/关闭，
     并选择状态属性、完成选项和日期属性；默认自动识别
     “状态 / 已完成 / 实际完成日期”。
  4. 已完成卡片会从右侧提醒栏的逾期/临期列表中移除，
     不再显示逾期/临期标签；“到期状态”属性也显示为“正常”。
  5. 这些按看板的设置保存在当前浏览器（每个账号各自保存）。

八点六、工时（工作日跨度属性）
  1. 看板“添加属性” → 选“工时（工作日）”：公式属性，
     按所选两个日期属性自动计算工作日跨度（含首尾、跳过周六日），
     卡片和表格视图直接显示天数。
  2. 开始/结束用哪两个日期属性，在提醒栏齿轮 →
     “工时 · 看板名”里逐个看板选择；不设置时自动取看板前两个日期属性。
  3. 看板日期少于两个的板块不显示该设置项。

九、到期推送（多渠道路报，每个账户独立配置）
  1. 支持渠道（提醒栏齿轮 → “推送渠道”下拉框切换）：
       飞书（群自定义机器人 Webhook，可配签名密钥）
       企业微信（群机器人 Webhook）
       钉钉（群机器人 Webhook，加签密钥填在签名密钥栏）
       方糖 / Server酱（填 https://sctapi.ftqq.com/SENDKEY.send）
       自定义 JSON（POST {"text": "..."}，如自建网关；密钥一并放在 secret 字段）
     切换渠道后 Webhook 输入框会给出对应格式示例。
  2. 推送节奏：
       推送日（星期）：勾选周一到周日哪些天推送，默认周一至周五；
       推送时段：只在该时间区间内推送（默认 9:00–17:00），夜间和周末不打扰；
       检测方式：
         按间隔——每 N 分钟检查一次，到点即发；
         每日定时——每天在指定时间（如 09:00）发一条汇总。
  3. 推送内容可按类型勾选：逾期 / 临期 / 待返，与右栏的统计口径完全同源——
     推送里的数字和右侧提醒栏看到的数字一致，不会出现两套算法。
  4. 链接地址：推送里卡片标题的跳转链接默认取 serverRoot（局域网地址），
     也可在齿轮里单独填写；建议用三点五节的规范地址。
  5. “立即推送”按钮：忽略推送日、时段、检测方式和当日去重，
     马上把当前内容发一次，用于测试配置是否正确。
  6. 未填写 Webhook 时使用 config.json 里的系统默认值。
  7. 同一张卡片同一天只提醒一次；修改截止日期后会重新提醒。
  8. 发送失败会记录在 data\focalboard.log（due reminder 字样）。

九点五、假勤助手（年假 / 调休）
  入口在顶部日期条上的徽标（如“调休 1 · 年假 5”）：
  1. 左点徽标：弹出当月月历，再点月历以外任意处自动关闭；
     右键徽标：钉住为悬浮小窗，可按住标题栏拖动，关闭后位置自动复位。
  2. 月历格子显示：公历日期、农历与节气（节气加粗）、法定节假日“休”/
     调休上班“班”角标（橙底=休、灰底=班）、本人假勤标记
     （加班、调休假、年假，支持半天½，颜色可在设置里自定义）。
  3. 记一笔：四种操作——
       加班（天）：累加调休余额；
       发放年假：手动给年假加天数（系统自动发放之外也可以手动补发）；
       请假（年假 / 调休）：扣减余额，余额不足时会直接拒绝并提示剩余额度；
       作废：把某条流水整条作废（打删除线，不再计入余额）。
     请假支持半天步长（0.5 天）。
  4. 年假自动发放：按入职日期（工作开始日期）对应工龄档，每年自动发放一次，
     档位按国家法定标准（工龄不满 1 年不发放；满 1 年 5 天；满 10 年 10 天；
     满 20 年 15 天）。首次打开或跨过发放日时由服务端自动补记。
  5. 清零规则：不再是“记录起 12 个月”，而是按“累积年份 + N 年的固定月日”清零。
     设置里年假/调休各选一档年数（当年 / 次年 / 隔一年 / 隔两年）加月、日：
       例：2026 年累积的调休，选“次年 + 4 月 30 日”→ 2027-04-30 作废；
       例：2026 年累积的年假，选“次年 + 3 月 31 日”→ 2027-03-31 作废。
     默认年假次年 3-31、调休次年 4-30，可自由修改；旧版按 12 个月存的
     记录会在读取时自动按新规则改写清零日，无需手工迁移。
  6. 扣减顺序：请假按“先过期先扣”（FIFO）消耗余额，快过期的先用掉。
  7. 余额显示：弹窗余额行统一带“距清零 X 个工作日”（只数周一到周五），
     徽标和流水里的过期额度会打删除线。
  8. 流水与导出：弹窗可切换“记一笔 / 流水 / 设置”，流水可逐条作废删除；
     “导出”下载纯文本台账（txt），含每笔日期、类型、天数、清零日与备注。
  9. 看板日历视图叠加：日历视图的日期格里同步显示本人的假勤标记和节气，
     只展示当前登录账号自己的数据；节假日名称与调休安排由服务端联网获取
     （国务院办公厅公开数据），拉取成功后缓存在 data 目录，断网时继续使用缓存。

九点六、工作流视图（看板分多行）
  1. 在看板上方工具栏“工作流”右侧的下拉框里，选择一个带选项的属性
     （例如“任务类别”），看板会按该属性的每个选项分成多行，每行是一个工作流。
  2. 每行有醒目的横向大表头，显示工作流名称和卡片数量；点击表头可折叠/展开该行。
  3. 工作流名称可直接点击修改（需要看板编辑权限），回车或点空白处保存。
  4. 点“+ 新建工作流”可在当前属性下新增一个工作流选项。
  5. 不同工作流之间不能互相拖动卡片，只能在同一个工作流内移动。
  6. 工具栏里的工作流标签可点击筛选：点一下隐藏，再点恢复；“全铺展示”显示全部。
  7. 筛选对看板、表格、画廊、日历视图同时生效。

九点七、紧凑模式与隐藏卡片
  1. 点工具栏“紧凑模式”，卡片会变成只显示标题 + 一个属性的小卡片，
     右侧下拉框可选择要显示哪个属性；再次点击恢复普通大小。
  2. 鼠标移到卡片上，点右上角“眼睛”图标可一键隐藏该卡片。
  3. 隐藏后工具栏会出现“显示已隐藏（n）”，点开可查看并逐张恢复。
  4. 隐藏和紧凑设置保存在当前视图中，切换视图互不影响。

九点八、成员面板（仅管理员）
  1. 第一个注册的账号自动成为管理员；用该账号登录后，
     点左下角用户名 → “成员面板”。
  2. 可以查看所有已注册成员及其在线/离线状态。
  3. 可以添加账号、为任意账号（包括自己）设置新密码、移除普通账号。
  4. 管理员对看板内容拥有和普通成员相同的编辑权限。

十、数据与备份
  所有数据都在 data 目录：
    data\focalboard.db      数据库（账户、看板、卡片）
    data\files\             上传的附件
    data\focalboard.log     运行日志（排查问题用）
    data\launcher.ini       托盘程序的设置（是否开机自启动）
    data\holidays-*.json    法定节假日缓存（删掉会自动重新拉取）
  假勤流水、提醒推送设置、成员偏好等存在数据库的用户偏好表里，
  备份时先退出程序，再复制整个 data 目录。
  换电脑时，复制整个程序目录（包含 data）即可。

十一、升级到本版本新增了什么
  1. 登录页修复：登录成功后自动进入看板，不再需要手动刷新。
  2. 假勤助手：顶栏徽标、月历弹窗/钉住悬浮窗、记一笔/流水/设置/导出、
     年假自动发放 + 手动发放、可选清零年数与月日、工作日倒计时、
     看板日历叠加假勤与节气。
  3. 推送升级：飞书单一渠道扩展为飞书/企业微信/钉钉/方糖/自定义 JSON，
     新增推送日（星期）、推送时段、每日定时模式、“立即推送”测试按钮。
  4. 工时（工作日）公式属性：两个日期属性自动算工作日跨度。
  5. 顶栏日期条：整条居中、新增干支纪年与农历显示；提示栏默认开启。
  6. 提醒栏齿轮整合：实际完成日期、工时跨度、推送设置在同一面板。
  升级后请强制刷新浏览器（Ctrl+F5）；数据无需迁移，旧格式自动兼容。

十二、退出
  右键托盘图标 → “退出”。退出时会停止服务端（包括开机自启的实例）。
  也可以运行：Focalboard.exe --quit
  开机自启后程序会在后台常驻，不使用时无需退出，资源占用很低。

十三、安全提示
  本程序使用 HTTP 明文传输，只建议在可信的局域网内使用。
  如需公网访问，请在前面加 HTTPS 反向代理（Nginx / Caddy），
  不要把 8088 端口直接暴露到公网。
  各渠道 Webhook 地址和签名密钥等同于机器人权限，请勿随意外发 config.json。
  建议定期备份 data 目录。

十四、常见问题
  - 端口被占用：关闭占用 8088 的程序，或修改 config.json 里的 port。
  - 退出后马上重开提示启动失败：新版本退出时会结束服务端并等待端口释放；
    如果仍失败，弹窗里会显示最近日志。常见原因是 config.json 写错
    （例如 true 误写成 ture），按日志提示修正后重开即可。
  - Windows 提示“已保护你的电脑”：点“更多信息” → “仍要运行”。
  - 同事访问不了：确认在同一局域网、防火墙已放行、网络类型不是“公用网络”。
  - 注册弹窗打不开 / 无法注册：说明已有账号，请用局域网地址登录后
    通过“邀请使用者”生成邀请链接（链接要用局域网地址打开才有效）。
  - 登录后停留在登录页：本版已修复；若仍有异常，Ctrl+F5 强刷或清理站点缓存。
  - 改了设置没生效 / 界面还是旧的：浏览器缓存了旧版前端，Ctrl+F5 强制刷新。
  - 顶栏徽标显示 0 / 没有年假：尚未设置工作开始日期，或工龄不满 1 年、
    今年额度已用完；在假勤弹窗“设置”里填工作开始日期后刷新。
  - 日历没有节假日“休/班”角标：服务端拉取节假日安排需要联网（出网到
    中国政府网公开接口），首次成功后会缓存；纯离线环境请手动维护缓存文件。
  - 收不到推送：检查推送开关是否启用、Webhook 是否完整、签名密钥是否正确、
    当前是否在推送日/时段内；可用“立即推送”按钮绕过限制直接测试，
    并查看 data\focalboard.log 中的 due reminder 日志。
  - 站内提醒不显示：没有到期卡片、或提前天数设置得太小。
  - 忘记密码：目前没有邮件找回功能，需要管理员处理数据库，请谨慎操作并先备份。
  - 不想开机自启：右键托盘 → “开机自动启动（登录后静默运行）” 取消打勾；
    或删除注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 FocalboardLAN。
  - 开机自启没反应：确认程序目录没被移动；移动过后在新位置运行一次即可修复。
  - 双击图标没反应：多用户登录 Windows 时，同一端口只能运行一个实例，
    如果已在其他登录会话运行，本会话会直接打开浏览器。
  - 模板只有英文/只有中文：模板跟随界面语言；切换语言后重新打开“新建看板”即可。
  - 到期状态显示“未设置日期”：卡片的截止日期为空，或看板里没有日期属性。

十五、技术说明
  服务端基于 Focalboard v8.0.0 源码编译，使用 SQLite 单文件数据库，
  开启原生账户登录（authMode = native），监听 0.0.0.0:8088，
  所有用户属于同一个团队，看板可按成员共享。
  定制接口：/api/v2/leaves/*（summary / records / settings / export）、
  /api/v2/top-bar/lunar（农历与节气）、法定节假日转发自公开数据源并缓存、
  到期推送在 duereminder 服务内按渠道分发（feishu/wecom/dingtalk/ftqq/custom）。
  假勤数据按账号存于服务端用户偏好（键 leaveRecords / leaveSettings），
  与浏览器无关，换设备登录同一账号数据一致。
  config.json 支持 // 与 /* */ 注释，方便直接写中文说明。
  托盘程序以当前用户身份运行，开机自启由 HKCU 启动项实现，不需要管理员权限。
