# 手机 APP 使用说明（Focalboard Mobile v1.1.0）

不改 Focalboard 网页源码，用原生 Android 外壳（WebView）把局域网版网页裁剪成三页手机应用。支持横竖屏、底栏长按 3 秒拖拽换位。

## 一、安装

1. 把 `FocalboardMobile-1.1.0.apk` 传到手机（微信/数据线/局域网均可）。
2. 点开安装，系统提示"未知来源"时允许。
3. 要求 Android 8.0 及以上（自带 WebView 即可，无需额外装浏览器内核）。
4. 手机必须与电脑（Focalboard 服务器）在**同一局域网**。
5. 已装 1.0.0 可直接覆盖安装（签名未变），服务器地址与登录态保留。

## 二、首次使用

1. 打开 APP，第一页填服务器地址，例如：
   ```
   http://192.168.1.100:8088
   ```
   （就是电脑托盘"局域网地址（点击复制）"里的那个地址，也可以只填 `192.168.1.100:8088`）
2. 点"连接"→ 出现网页登录页 → 用现有账号登录或注册。
3. **在任意一页登录一次，其余两页会自动刷新成已登录状态**，无需逐页登录。

底部三个页面：

| 页面 | 内容 |
|---|---|
| 看板 | 完整看板，左右栏自动隐藏、看板满屏；底部多一条**横向拖动栏**（见第三节） |
| 日历 | 顶栏日期条对应的**假勤日历弹窗**整页显示：月历、余额、休/班、农历节气、假勤标记；默认展开「流水」，全部记录可滚动看完；「记一笔 / 流水 / 设置 / 导出」仍可用 |
| 逾期设置 | 原右侧提醒栏整页显示：逾期/临期/待返开关、推送渠道与时段、Webhook、各看板逾期日期等；顶部齿轮设置默认展开；点某张卡片会跳到"看板"页并定位到该卡片 |

## 三、看板横向拖动栏

看板列多、手机屏幕窄时，用底部蓝色滑块横向移动看板，**不会误拖卡片**：

- 拖动滑块：整条看板按比例左右移动。
- 点左右两侧的 `‹` `›`：每次约移动一列。
- 只在看板列超出屏幕时出现；列表/表格等没有横向滚动的视图会自动隐藏。
- 滑块只驱动看板横向滚动，卡片本身的点开、长按拖拽不受影响。

## 四、底栏长按拖拽换位

1. **按住底栏任意图标 3 秒不动**，出现蓝色提示条"已进入排序模式"。
2. 左右拖动图标，越过相邻图标即交换位置。
3. 松手即退出排序，顺序自动保存，下次打开保持。

## 五、横屏

直接旋转手机即可（支持四个方向）。看板页横屏后列更多；日历页横屏月历自动铺满；设置页横屏为宽列表。

## 六、换服务器

当前版本如需更换服务器地址：手机系统设置 → 应用 → Focalboard → 清除数据，再打开重新填地址。

## 七、常见问题

- **打不开/一直白屏**：确认手机和电脑同一 Wi-Fi；电脑端 Focalboard 在运行；地址带 `http://` 和端口。
- **日历页空白**：先确认已登录；日历弹窗需要顶栏日期条加载完成，网络慢时等 2–3 秒会自动出现。
- **看板页底部没有滑块**：说明当前视图没有横向溢出（列不多或处于表格/列表视图），属正常。
- **点设置页卡片没反应**：需要该卡片出现在逾期/临期/待返列表里；点后会自动切到看板页。
- **电脑换了 IP**：按"换服务器"清除数据重填。

## 八、给维护者

- 工程源码在仓库 `mobile/`（Kotlin，单 Activity + 3 WebView）。
- 构建命令（Windows Git Bash）：
  ```bash
  export JAVA_HOME=D:/android-build/jdk17
  export ANDROID_HOME=D:/android-build/sdk
  cd mobile && /d/android-build/gradle-8.7/bin/gradle assembleRelease
  ```
- 签名配置：复制 `mobile/keystore.properties.example` 为 `mobile/keystore.properties`，填入自己的 keystore 路径与密码（该文件已被 git 忽略，不要提交真实密钥）。
- 页面裁剪脚本在 `app/src/main/java/com/focalboard/mobile/InjectionJs.kt`：
  - 第 1 页只裁剪 CSS；
  - 第 2 页自动点 `.DueTopBar__calendar` 打开假勤弹窗，加 `.fb-mobile-leave` 整页化并点「流水」；
  - 第 3 页自动展开右栏与齿轮设置；
  - 三页都通过 `FocalboardAndroid` JS 桥回报登录态、转发卡片点击。
- 原生横向拖动栏在 `MainActivity.kt`（`SeekBar` 驱动 `.Kanban.scrollLeft`，450ms 轮询同步）。
- minSdk 26（Android 8.0），targetSdk 34，versionCode 2 / 1.1.0。
- 网页升级后若 `.Kanban`、`.LeaveCalendar`、`.DueSidebar__*` 等类名变化，需同步调整 `InjectionJs.kt`。
